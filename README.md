# Hey, I'm Chris Howarth 👋

**Full-stack Software Engineer at the BBC** — building the systems that power live sport, news, and entertainment for millions of people.

I work across the complete delivery stack: React and TypeScript on the client, Node.js middleware, backend API composition, and platform routing infrastructure. Most of my work lives inside BBC Live — real-time pages that have to work, at scale, all the time.

I'm also the person on my team most likely to be building an AI tool nobody asked for, writing a decision framework for which agent to use, or talking someone into trying Copilot for the first time.
